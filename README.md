# PatchPad Homebrew tap

Install [PatchPad](https://github.com/Patchbay-s/PatchPad) for Apple silicon:

```sh
brew tap Patchbay-s/patchpad
brew install --cask patchpad
```

The cask installs the
[latest release](https://github.com/Patchbay-s/PatchPad/releases/latest) DMG, signed with an
Apple Developer ID and notarized. Xbox controllers work over Bluetooth on macOS; DualShock 4
controllers work over USB and Bluetooth. Intel builds are not available yet.
